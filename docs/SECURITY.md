# Security

## How the site works

NodeFlow On-site is a static site with no accounts, no login and no database.
The Arduino sketch is built in your own browser and is only ever saved as a
file you download.

The one thing the site sends is a short research record (name, email, country,
file name, an optional note and the sensor setup). It is sent when you confirm
a download and only after you have read the consent form. There is no
analytics, no advertising cookies and no third-party trackers. Your details and
saved setups are kept in your own browser and can be cleared at any time with
**Clear** on the generator page or by clearing this site's data.

The full policy is on the
[privacy page](https://fernlag.github.io/NodeFlow-Onsite-Sensing-System/privacy.html).

## Reporting a problem

If you think you have found a security issue, please report it privately to
the project team rather than opening a public issue, and give us a reasonable
amount of time to fix it before sharing details. The contact address is in the
footer of the site.
