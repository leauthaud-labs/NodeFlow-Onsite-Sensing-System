Thank you. Your configuration choice helps us understand how the system is being used.

This page will walk you through the process of uploading this code onto your Arduino board. If you have not done so already, please download the Arduino IDE application here. Note that no additional software, packages or configuration are needed. You will also need a USB B to USB A cable, the square-ended kind that comes with most printers, to connect the board to your computer.

  1. 1

    Open the file

    Find the .ino file in your downloads folder and open it with the Arduino IDE. The Arduino IDE will ask to move this file into a new folder. Select yes or OK.

  2. 2

    Choose the board and the port

    Plug the Arduino into your computer with the USB cable. In the Arduino IDE, set Tools › Board to Arduino Uno. On some versions of the Arduino IDE it sits one level deeper, under Tools › Board › Arduino AVR Boards › Arduino Uno. Then set Tools › Port to the port that appeared when you plugged the board in. If no port appeared, try a different USB cable: many cables carry power but no data.

  3. 3

    Upload

    Press the upload arrow. When the Arduino IDE says Done uploading, the display starts showing readings.

  4. 4

    Read the screen

    The top line of the Arduino screen shows the port number, the abbreviated sensor name and the value, like A2 WM200SS 34 kPa. The bottom line shows the bar, state or warning you chose. Press the board's left and right buttons to step through your sensors. The backlight goes out after five minutes without a button press; any button wakes it.

    Some choices leave the bottom line blank, and that is normal. Raw value, Transformed Raw Value 0-100 and Temperature put everything on the top line. No visualization goes further: the sensor is still read, but nothing about it appears on the screen at all. If you want the bottom line used, choose a visualization that draws there, such as Percentage bar or one of the State options.

If something looks wrong

The screen is blank or shows blocks
Near one corner of the LCD board there is a small blue box with a screw slot in the middle. That is the contrast dial. Turn it slowly with a small screwdriver until the text appears. A new board is often set to full contrast, which shows a row of solid blocks, or to none, which shows nothing at all.
A port reads No Sensor
Nothing is detected on that pin. Check the wiring at both ends. On a Watermark going through the 200SS-VA3 adapter, remember the adapter refreshes each channel every five minutes and holds the previous value in between, so give it time after powering up.
The percentage looks backwards
Higher percentages always mean wetter soil, in every measurement except the raw reading, which reports the sensor faithfully. If a capacitive probe reads backwards, your air and water calibration values are probably swapped. Generate a file with the raw value as the measurement, note the reading in open air and in water, then put those two numbers back into the form.
A battery warning appears
The code measures the supply voltage against the chip's internal 1.1 V reference. It only works on battery power through the barrel jack. On USB power, including a USB power bank, the reading is not meaningful and the warning can be ignored.
The calibration values in the form or the display values do not match my soil
Calibration values and soil-texture thresholds are your field's, not ours. The defaults are a starting point. Change them in the form and generate the file again.
